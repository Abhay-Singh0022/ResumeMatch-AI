# ResumeMatch AI 🚀
### Enterprise Talent Acquisition & Semantic Matching Engine

ResumeMatch AI is a high-performance recruitment intelligence platform designed to automate and elevate candidate evaluation through deep semantic parsing, multi-vector resume profiling, and AI-driven insights.

---

## 🌟 Key Features
* **Enterprise Recruiter Leaderboard**: Ranks multiple candidate resumes against a job description in a clean, high-density UI layout.
* **Semantic Resume-to-JD Parsing**: Powered by Apache PDFBox, custom keyword matrices, and synonym mapping.
* **Deep AI Insights Engine**: Generates comprehensive executive recruiter verdicts, structured core technical strengths, and targeted interview probing topics.
* **Batch Mode Processing**: Seamlessly evaluates multiple PDF resumes simultaneously.

---

## 🛠️ Tech Stack
* **Backend**: Java, Spring Boot, Apache PDFBox
* **Frontend**: HTML5, CSS3, Bootstrap 5, Modern JavaScript (ES6)
* **Design Architecture**: Responsive Glassmorphism UI optimized for recruiters
